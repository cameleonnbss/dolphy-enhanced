# Dolphy Enhanced

[FR](README.fr.md) · **EN** · [RU](README.ru.md) · [ES](README.es.md) · [DE](README.de.md)

Расширенный форк [Dolphy](https://github.com/unvoiddd/Dolphy-App) — Android-инструмент
для исследования беспроводных протоколов, работы с NFC/RFID и эмуляции оборудования.
Для большинства модулей root не нужен.

**Разработано [camzzz](https://github.com/cameleonnbss)** · оригинальный проект
[unvoiddd](https://github.com/unvoiddd) · GNU GPL v3.

> ⚠️ Используйте только на своих устройствах и сетях или при наличии явного
> разрешения. При первом запуске приложение просит принять эти условия.

---

## Что добавлено в форке

- **16 языков** с откатом на английский, выбор языка с нативными названиями,
  поддержка RTL для арабского.
- **База NFC-карт**: 90 технических карточек (ATQA, SAK, AID, память, защита,
  вердикт о клонируемости) — MIFARE, DESFire, FeliCa, Calypso, EMV, пропуска
  доступа, транспортные карты, документы.
- **База OUI IEEE**: 335 префиксов, производитель показывается в BLE-сканере.
- **Генератор модулей через ИИ**: любой OpenAI-совместимый endpoint.
  Поток: описать → сгенерировать → **прочитать код** → установить.
- **Потоковый движок wordlist**: импорт больше не идёт через SharedPreferences.
- **Определение root** с названием менеджера и версией, с кэшированием.
- **Тема Material 3 Expressive**: акцентный цвет, масштаб интерфейса, анимированный
  фон, шрифт Flipper.

## Установка

Скачайте подписанный APK из [релизов](https://github.com/cameleonnbss/dolphy-enhanced/releases).

## Сборка

```bash
# Windows
gradlew.bat assembleRelease

# Linux / macOS (в репозитории нет wrapper-скрипта — нужен Gradle 8.11+)
gradle assembleRelease
```

Подпись релиза берётся из неверсионированного `keystore.properties`.
