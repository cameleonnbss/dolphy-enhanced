# Dolphy Enhanced — Русский

Улучшенный форк [Dolphy](https://github.com/unvoiddd/Dolphy-App) — Android-мультитул
для исследования беспроводных протоколов, NFC/RFID и эмуляции оборудования.
Большинство модулей работают без root.

**Доработано [camzzz](https://github.com/camzzz)** · исходный проект —
[unvoiddd](https://github.com/unvoiddd) · GNU GPL v3.

> ⚠️ Используйте только на оборудовании, которым вы владеете или тестирование
> которого вам явно разрешено. Глушение, блокировка или перехват чужих
> устройств незаконны в большинстве стран и **не входят** в эту версию. При
> первом запуске появляется экран принятия условий.

## Что добавляет этот форк

- **16 языков, все полные**: в `values/` теперь английский, поэтому
  частично переведённый язык откатывается на английский, а не на русский.
  Все шестнадцать локалей содержат 1155 ключей.
  Выбор языка с поиском, родные названия, поддержка RTL (арабский) и режим
  «как в системе».
- **Списки паролей, которые больше не вешают телефон**: встроенные наборы
  читаются построчно, импорт нормализуется один раз и сохраняется в файл (никакого
  JSON-блока в SharedPreferences) и **сгенерированные шаблоны** — сотни тысяч
  кандидатов из масок, без веса в APK.
- **База карт**: 37 документированных семей NFC/RFID (MIFARE, DESFire, NTAG,
  FeliCa, Calypso, EMV AID, HID, LEGIC, транспортные карты, ePassport…), поиск
  по названию, ATQA, SAK или AID.
- **Определение root**: есть ли root, какой менеджер (Magisk / KernelSU /
  APatch / SuperSU), путь и версия `su`, с кэшем и таймаутом.
- **Экран принятия условий** при первом запуске: только образовательные цели и
  авторизованные устройства, повторно читается в Настройки → О приложении.
- **Поиск** на экране функций, новая адаптивная иконка, название
  «Dolphy Enhanced».

## Сборка

```bash
gradlew.bat assembleDebug     # Windows
./gradlew assembleDebug       # Linux / macOS
```

Нужны JDK 17+ и Android SDK 36. APK появится в
`app/build/outputs/apk/debug/`.
